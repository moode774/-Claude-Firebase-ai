## عن المشروع

أداة متقدمة تتيح ربط **Claude Desktop** مباشرة بـ Firebase Firestore بدون أي برمجة إضافية. تمكّنك من قراءة وكتابة وتحديث البيانات عبر أوامر طبيعية من داخل Claude.

## كيف يعمل

```
Claude Desktop ←→ MCP Server ←→ Firebase Firestore
```

## التثبيت

```bash
# 1. استنسخ المشروع
git clone https://github.com/moode774/-Claude-Firebase-ai.git

# 2. ثبّت الاعتماديات
npm install

# 3. اضبط إعدادات Firebase في claude_desktop_config.json
```

## المميزات

- 🔗 ربط مباشر بين Claude وFirebase
- 📖 قراءة وكتابة البيانات بأوامر طبيعية
- ⚡ إعداد سريع بدون برمجة
- 🔧 يعمل مع Claude Desktop
